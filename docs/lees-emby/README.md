## 从找到影片，到安心看完

- **浏览自己的片库** — 首页推荐、按媒体库分组的最近添加、海报墙与条目详情，按电影、剧集和分季查看内容。
- **连接多个账户** — 多个服务器或账户可以同时登录，左栏按账户展示媒体库，搜索可汇总各账户的结果。
- **整理收藏与观看状态** — 支持多选，批量收藏或标记已看；播放进度同步到 Emby 服务器。
- **按习惯播放** — 切换音轨和字幕、选择分集、调整倍速，查看章节与播放信息。
- **管理媒体信息** — 拥有服务器管理员权限时，可编辑条目图片、按提供方和语言搜索图片，或刷新当前条目的元数据。

## 音乐库，也有完整的播放体验

| 功能 | 体验 |
| --- | --- |
| 分类浏览 | 推荐、专辑、专辑艺人、艺人、作曲家、类型、歌曲与文件夹；推荐页展示最新音乐、最近播放与经常播放 |
| 专辑详情 | 查看曲目与同艺人的其他专辑，顺序播放、随机播放或收藏 |
| 歌曲播放 | 点击歌曲直接播放，展示封面与曲目信息；有可用歌词时显示歌词，带时间轴的歌词跟随进度滚动 |
| 队列与混播 | 专辑、歌曲可加入播放队列，支持跨账户队列、随机播放、单曲循环与全部循环 |
| 持续收听 | 离开播放页后，底部播放条继续控制上一首、下一首、暂停、音量、收藏、歌词与队列 |

音乐来自你连接的 Emby 音乐库；歌词是否可用取决于媒体条目与服务器提供的数据。

### 本地文件与 NAS 蓝光目录

无需登录即可打开本地视频、音频或蓝光文件夹，也支持拖入文件。本地播放保留最近播放与续播点，历史最多保留 30 条；音轨、字幕、章节与 Anime4K 可在播放器内调整。

播放 Emby 库中需要直接读取 NAS 的 BDMV 目录时，在设置中选择「适用账户」，配置「BDMV 直读」的服务器媒体根路径与本机可访问的盘符或 UNC 根路径。对应目录必须已能从 Windows 访问；应用通过映射读取完整蓝光目录。当前不支持 ISO 光盘映像。

## 开始使用

1. 在 [Releases](https://github.com/lyq2010/lee-releases/releases?q=%22Lee%27s+Emby%22&expanded=true) 下载 `LeesEmby_*_x64-setup.exe`。
2. 运行安装程序；默认安装到 `%LOCALAPPDATA%\Programs\Lee's Emby`，可选择其他当前用户可写目录，无需管理员权限。
3. 打开应用，填写自己的 Emby 服务器地址并登录；也可选择本地播放，无需服务器账户。
4. 从左栏进入电影、剧集或音乐库，或直接打开本地文件，开始播放。

支持 **Windows 11 22H2 或更高版本、x64**。服务器播放需要已有的 Emby 服务与可用账户，本应用不提供媒体资源。

安装器将内置的 `CN=Lee` 证书写入当前用户证书库。自签名安装包仍可能触发 Windows SmartScreen 提示，请确认下载来源。

## 数据、更新与隐私

- **账户凭据** — Emby 访问令牌保存在 Windows 凭据管理器中，不写入数据库或诊断摘要。
- **本地数据** — 配置数据库、诊断日志与更新缓存位于安装目录的 `data` 文件夹。覆盖升级保留用户数据；卸载默认保留，勾选「清理用户数据」后才清理。
- **网络访问** — 应用不做遥测上报；媒体访问、弹幕和评分查询按配置的服务执行。本地弹幕默认关闭，首次启用时会说明将向已配置服务发送文件名、大小和时长。
- **更新检查** — 应用启动时及每 4 小时检查更新，发现新版本后显示悬浮更新按钮，点击后下载、校验并安装。检查本身不会安装更新。
- **安装校验** — 更新前校验大小、SHA-256、Minisign 签名与版本，完成后自动重启。安装失败时尝试恢复旧程序，保留用户数据。

发行版同时提供安装包、独立签名、公钥证书和版本清单。设置页可清理已下载的更新安装包、媒体库内存缓存与评分缓存；账户、播放记录和弹幕绑定会保留。
