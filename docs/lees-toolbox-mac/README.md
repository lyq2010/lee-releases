## 把重复的表格工作交给工具

- **建筑板与冷库板** — 按对应业务流程生成和更新项目概览表。
- **汇总与每日发货** — 整理板材汇总和发货数据，减少重复处理。
- **合同与收款** — 处理概览中的合同收款等业务数据。
- **连接生产管理系统** — 在具备公司系统访问权限时，主动拉取所需业务数据。

业务工作簿在本机处理，沿用现有业务流程与表格格式。

## 开始使用

1. 在 [Releases](https://github.com/lyq2010/lee-releases/releases?q=native-v&expanded=true) 下载 `Lee.s.Toolbox.Mac_*_macOS_arm64.dmg`。
2. 打开 DMG，将应用拖入「应用程序」。
3. 首次打开若被系统阻止，前往「系统设置 → 隐私与安全性」确认允许。
4. 选择建筑板、冷库板或日常工具，按页面提示添加文件并执行。

支持 **Apple Silicon、macOS 14 或更高版本**。应用采用 ad-hoc 签名，不使用 Developer ID 或 Apple 公证；更新通过应用内入口获取，并校验来源、大小、SHA-256 与签名。

业务功能面向公司现有流程；「从系统拉数」需要相应网络与账号权限。日常工具可独立使用。

## 业务文件在本机处理

工作簿正文不上传。连接生产管理系统时，会按用户操作发起业务查询；在线工具、网页启动器与应用更新按各自用途访问网络。请勿在公开反馈中附上真实业务工作簿或内部系统地址。
