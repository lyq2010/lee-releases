## 把日常维护集中到一处

- **看清磁盘空间** — 查看本机固定磁盘的可用空间，判断是否需要清理。
- **清理可重建的缓存** — 按分类查看扫描结果、目标路径与占用空间，选择后再执行。
- **管理开机启动** — 审查启动项、计划任务与服务；变更保留恢复快照，可从历史中逐项恢复。
- **拦截你指定的弹窗** — 通过准星拾取、截图或窗口记录创建规则，按明确规则拦截。
- **处理文件占用** — 查看占用进程、解除占用，并从资源管理器右键菜单进入。
- **查看执行结果** — 清理后展示实际释放空间、成功项和未能处理的目标。

## 先看清，再决定

| 场景 | 处理方式 |
| --- | --- |
| 垃圾清理 | 执行前复核目标；账号、聊天、文档、下载、同步和离线媒体等目录不纳入普通缓存规则 |
| 卸载残留 | 单独列出完整明细，默认不勾选；可能包含原应用配置和用户数据 |
| 启动项调整 | 保留恢复快照，首页提供待恢复改动入口 |
| 弹窗拦截 | 由用户明确指认目标，不按窗口外观自动判断广告 |
| 文件删除 | 提供强制删除与受限的传统 HDD 覆盖删除；执行前确认，删除操作不可恢复 |
| 系统权限 | 主程序以普通用户权限运行，必要的系统修改才请求提权 |

## 开始使用

1. 在 [Releases](https://github.com/lyq2010/lee-releases/releases?q=lees-system-toolbox&expanded=true) 下载 `lees-system-toolbox_*_x64-setup.exe`。
2. 运行安装程序，完成后从开始菜单打开工具箱。
3. 选择需要的工具；清理时先扫描、查看明细，再确认执行。

支持 **Windows 11 22H2 或更高版本、x64**。在「关于」页手动检查更新，应用会校验更新包后安装。

## 数据留在本机

扫描与规则匹配在本机完成，不上传窗口、文件、浏览器或启动项信息，不包含遥测。应用不扫描 NAS、UNC 或映射网络盘；网络访问仅用于用户主动检查更新。

不安装内核驱动或常驻高权限服务。需要修改系统时，由按需启动的提权组件执行。
